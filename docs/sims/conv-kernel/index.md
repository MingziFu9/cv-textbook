## 教学说明

**学习目标**

1. 能说出卷积“对应位置相乘、再全部加起来”的计算过程，并手算一格（应用）；
2. 能根据卷积核的九个数，判断它大致起模糊、锐化还是找边缘的作用（理解）；
3. 能解释为什么同一个卷积核在整张图上滑动，就能把所有同类特征都找出来（理解）。

**画面与操作**

- 左边是从照片蓝框处取出的 10×10 灰度值，中间是 3×3 卷积核，右边是输出；
- “下一步”让窗口滑动一格，下方写出这一格的完整算式；“自动播放”连续滑动；
- 六个预设卷积核，也可以直接改九个数（支持 `1/9` 这样的分数）；
- 下方右图是同一个核作用在整张照片上的结果，改核以后立即更新。

**数据来源**：浏览器读取照片像素并按 0.299 红 + 0.587 绿 + 0.114 蓝换算灰度，卷积计算与实验 3-2 的 `cv2.filter2D` 相同（边缘一圈不计算）。照片缩小自 labs/data/images/ 中的 drive_city.jpg 和 lane_white.jpg。

**课堂用法建议**

1. 先用“竖直边缘”核单步走几格，让学生自己手算下一格，再点“下一步”核对；
2. 讨论：竖直边缘核在亮暗不变的地方输出接近 0，在左暗右亮的地方输出是大正数，为什么？
3. 让学生把核改成“水平边缘”，预测车道线和车顶哪个更明显，再验证。
