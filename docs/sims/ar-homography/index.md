## 教学说明

**学习目标**

1. 能说出增强现实“找标记 → 算单应性矩阵 → 变形贴图”三步（记忆、理解）；
2. 能解释为什么四对对应点就能决定一个单应性矩阵，以及角的顺序为什么重要（理解）；
3. 能比较“透视变形”和“只缩放平移”的效果差别（分析）。

**画面与操作**

- 背景是路面上平放的一块 ArUco 标记码，红点是程序找到的四个角，编号 1～4 依次是左上、右上、右下、左下；
- 拖动任意红点，贴图实时跟着变形，下方显示单应性矩阵 H 和四对点的坐标；
- “贴什么”切换导航箭头、方格纸（最容易看出透视）和提示牌；
- “四个角”有四个预设：对准标记码、不做透视（外接矩形）、换个角度看、把 3、4 号角弄反。

**数据来源**：背景由编者用 `labs/data/make_marker_scene.py` 合成，裁剪和角点检测脚本为 `tools/figures/ch09_sims.py`，与实验 9-2 相同。

**课堂用法建议**

1. 先选“方格纸”，让学生观察“近处格子大、远处格子小”，说明这就是透视；
2. 点“不做透视”，问学生箭头为什么看起来像“立”在路上；
3. 点“把 3、4 号角弄反”，讨论为什么标记码要设计成不对称的图案；
4. 让学生自由拖动，把箭头拖成“躺在旁边车道上”的样子，再说出 H 的哪几个数变化最大。
