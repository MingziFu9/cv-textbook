## 教学说明

**学习目标**

1. 能说出语义分割、实例分割、全景分割的输出分别是什么（记忆）；
2. 能解释为什么语义分割分不清挨在一起的两辆车，而实例分割可以（理解）；
3. 能根据任务选出合适的分割方式，例如“算路面占比”和“数一数有几个人”（应用）。

**画面与操作**

- 两张 KITTI 行车照片，四种模式：原图、语义、实例、全景，可调透明度；
- 鼠标移到画面上，下方显示这个像素的类别或实例编号；
- 图例列出画面中出现的类别和实例。

**数据来源**：编者用 yolo26n-sem 和 yolo26n-seg 实际分割得到，全景分割由两者合并（人和车用实例结果，其余用语义结果），生成脚本为 `tools/figures/ch06_sims.py`。真正的全景分割模型是一次输出的，这里用合并的方法示意它的输出长什么样。

**课堂用法建议**

1. 在“城市街道”的语义模式下，让学生找左边停着的两辆车分界在哪里，再切到实例模式对比；
2. 在“行人过马路”上数一数实例有几个人，讨论有没有漏掉远处的人、为什么。
