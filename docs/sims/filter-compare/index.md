## 教学说明

**学习目标**

1. 能用“用邻居的值替换自己”解释均值、高斯、中值三种滤波（理解）；
2. 能手算 3×3 窗口的均值和中值（应用）；
3. 能根据噪声类型选择滤波方法，说出窗口越大越模糊的代价（评价）。

**画面与操作**

- 三种图：街道加椒盐噪声、街道加高斯噪声、实验 2-2 均衡化后自带噪点的夜间画面；
- 四种处理：不处理、均值、高斯、中值；窗口大小 1×1 到 9×9；
- 在任一张图上点一下，下方列出这个点周围 3×3 的灰度值，以及三种算法分别算出的结果。

**数据来源**：浏览器实时计算，算法与 `cv2.blur`、`cv2.GaussianBlur`、`cv2.medianBlur` 相同（高斯权重按 OpenCV 默认公式由窗口大小算出）。街道照片裁自 drive_city.jpg（KITTI，CC BY-NC-SA 3.0）。

**课堂用法建议**

1. 椒盐噪声下分别试均值和中值，让学生点一个白色噪点，对比三个算法的结果，说说中值为什么能把它“抹掉”；
2. 把窗口从 3 拉到 9，观察车牌、车道线的清晰度，讨论“去噪”和“保细节”怎样取舍。
