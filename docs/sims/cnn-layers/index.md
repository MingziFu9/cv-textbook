## 教学说明

**学习目标**

1. 能说出卷积神经网络越往后的层，特征图越小、通道越多、看到的东西越抽象（理解）；
2. 能把第 3 章的手工卷积核和 CNN 第一层学出的卷积核联系起来（理解）。

**画面与操作**

- 上方流程条显示输入、五个层和输出的形状，点哪一层就显示哪一层；
- 左边是输入图片和模型的前三个判断，右边是这一层最活跃的 16 张特征图，下方是这一层的说明；
- 三张图：白色厢式车（模型认得很准）、行人（ImageNet 的 1000 类里没有“人”，所以认不准）、车道。

**数据来源**：编者用 yolo26n-cls 预训练模型实际提取的特征图（第 0、2、4、6、8 层），脚本为 `tools/figures/ch04_featuremaps.py`。每张特征图单独拉伸到 0～255，所以只能比较“哪里亮”，不能比较不同图之间的绝对大小。

**课堂用法建议**

1. 先看第 0 层，让学生找出“只在竖直边缘亮”和“只在白色区域亮”的特征图，联系第 3 章的 Sobel 核和 HSV；
2. 逐层往后点，讨论：为什么到第 8 层人已经看不懂了，模型却能据此判断类别？
3. 切换到“行人”，看模型的判断，引出“预训练模型只认识它学过的类别，要认新类别就要迁移学习”。
