Canny 双门槛：强边缘直接留，弱边缘看“有没有靠山”

拖动低门槛和高门槛。变化强度高于高门槛的是“强边缘”（白）；介于两个门槛之间的是“弱边缘”，和强边缘连着的留下（黄），孤零零的丢掉（暗红）；低于低门槛的直接丢掉。

计算步骤与 OpenCV 的 cv2.Canny 相同：Sobel 算变化强度和方向 → 只保留方向上最强的点（细化成一条线）→ 双门槛 → 弱边缘沿 8 个邻居连到强边缘才保留。强度用 |水平变化| + |竖直变化| 计算（cv2.Canny 的默认算法），结果与 OpenCV 基本一致。
