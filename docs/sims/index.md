# 交互动画

这些动画都是普通网页，不需要安装任何软件，也不需要联网调用接口，在电脑和手机浏览器上都能打开。每个动画都嵌在对应章节的正文里，也可以从这里单独打开，适合课堂演示。

<!-- sims:start -->
| 章 | 动画 | 你可以做什么 |
|---|---|---|
| 第 1 章 | [像素放大镜](pixel-zoom/index.md) | 点一点行车照片，看每个像素的红、绿、蓝三个数字，拖动分辨率体会图片的形状（高、宽、通道） |
| 第 2 章 | [滤波器对比](filter-compare/index.md) | 同一张噪声图换用均值、高斯、中值滤波和不同窗口大小，点一个像素看它的 3×3 邻居怎样算出新值 |
| 第 2 章 | [HSV 调色板](hsv-picker/index.md) | 拖动色调、饱和度、亮度三组滑块，看哪些像素被选中，体会用 HSV 按颜色找车道线、换证件照底色的原理 |
<!-- sims:end -->
