# 交互动画

这些动画都是普通网页，不需要安装任何软件，也不需要联网调用接口，在电脑和手机浏览器上都能打开。每个动画都嵌在对应章节的正文里，也可以从这里单独打开，适合课堂演示。

<!-- sims:start -->
| 章 | 动画 | 你可以做什么 |
|---|---|---|
| 第 1 章 | [像素放大镜](pixel-zoom/index.md) | 点一点行车照片，看每个像素的红、绿、蓝三个数字，拖动分辨率体会图片的形状（高、宽、通道） |
| 第 2 章 | [滤波器对比](filter-compare/index.md) | 同一张噪声图换用均值、高斯、中值滤波和不同窗口大小，点一个像素看它的 3×3 邻居怎样算出新值 |
| 第 2 章 | [HSV 调色板](hsv-picker/index.md) | 拖动色调、饱和度、亮度三组滑块，看哪些像素被选中，体会用 HSV 按颜色找车道线、换证件照底色的原理 |
| 第 3 章 | [Canny 双门槛](canny-threshold/index.md) | 拖动 Canny 的低门槛和高门槛，看强边缘、连上的弱边缘和被丢掉的弱边缘怎样变化 |
| 第 3 章 | [卷积核滑动](conv-kernel/index.md) | 看一个 3×3 卷积核在灰度图上一格格滑动、乘加出输出，改九个数得到模糊、锐化和边缘效果 |
| 第 4 章 | [CNN 逐层看到了什么](cnn-layers/index.md) | 选一张图和一层，看分类模型各层最活跃的特征图从边缘、纹理到抽象部件的变化，以及特征图越来越小、通道越来越多 |
| 第 4 章 | [混淆矩阵读图](confusion-matrix/index.md) | 点混淆矩阵的任意一格，看真实是某类、被认成某类的验证集图片，找出模型认错的原因 |
| 第 5 章 | [置信度门槛](confidence-threshold/index.md) | 拖动置信度门槛，对照人工标注看认对、误检、漏检和精确率、召回率怎样此消彼长 |
| 第 5 章 | [IoU 计算器](iou-calculator/index.md) | 拖动检测框，实时看它和标准答案的交集、并集和交并比，理解 IoU 0.5 的含义 |
| 第 6 章 | [点一下分割](sam-click/index.md) | 在行车照片上点一下，看 SAM 风格的掩膜亮出被点中的完整一块，体会“分割一切”不需要类别、不需要训练 |
| 第 6 章 | [三种分割对比](seg-types/index.md) | 同一张行车照片切换语义分割、实例分割和全景分割，鼠标移到像素上看它被分成了什么 |
| 第 7 章 | [动作是一段时间](action-timeline/index.md) | 拖动时间轴看俯卧撑视频的肘关节角度曲线，调撑起、压下门槛和“连续几帧”规则，加关键点抖动，体会动作识别要看一段时间 |
| 第 7 章 | [跟踪号码牌](track-ids/index.md) | 看模拟车流在桥下被遮挡、检测器偶尔漏检时，跟踪器的号码牌能不能保持不变，比较“只看重叠”和“预测位置 + 记住几帧”两种方法 |
| 第 8 章 | [加噪与去噪](diffusion-noise/index.md) | 拖动步数，看一张行车照片怎样一步步变成噪声，再从噪声一步步“洗”回图片，理解扩散模型的训练和生成 |
| 第 8 章 | [放大对比滑块](sr-compare/index.md) | 同一张 100×40 的小图用最近邻、双三次插值和 Real-ESRGAN 超分辨率放大 4 倍，拖动滑块左右对比，再和原图比，看清超分辨率“猜”出的细节 |
| 第 9 章 | [增强现实贴图](ar-homography/index.md) | 拖动标记码的四个角，看导航箭头、方格纸、提示牌怎样按单应性矩阵“贴”在路面上，对比不做透视和角的顺序弄反时的效果 |
