# 2.1 OpenCV 入门

## 图像处理 vs 图像识别
| | 图像处理 | 图像识别（第 4～7 章） |
|---|---|---|
| 输出 | 一张改过的图 | 类别、框、轮廓等答案 |
| 例子 | 调亮、去噪、换底色 | 认出轿车、找出行人 |
| 工具 | OpenCV | YOLO 等模型 |

- 图像处理常常是识别的**前一步**

::: notes
辅助驾驶里，先把画面调亮、去噪、裁出路面，再交给模型。OpenCV 2000 年由英特尔发起，开源免费。
:::

## 读、显示、保存三件套
| 函数 | 要注意 |
|---|---|
| `cv2.imread(路径)` | 路径错了**不报错**，返回 `None` |
| `cv2.imwrite(路径, 图)` | 扩展名决定格式 |
| `plt.imshow(图)` | 先把 BGR 转成 RGB |
| `cv2.imshow(…)` | 只能在本机用 |

- OpenCV 进、OpenCV 出，**不用转**
- 交给 Matplotlib 等别的库，**要转**

::: notes
cv2.cvtColor 是本章最常用的函数：COLOR_BGR2RGB、COLOR_BGR2GRAY、COLOR_BGR2HSV。颜色显示得怪（黄变青、肤色变蓝），几乎都是忘了转。
:::

# 2.2 几何变换

## 裁剪、缩放、旋转、翻转
![几何变换与灰度转换](images/geometry.jpg)
- 裁剪 = 切片 `img[行, 列]`
- 缩放 `cv2.resize(img, (宽, 高))`：**先宽后高**
- 翻转可以“多出”训练图片

::: notes
切片和 shape 是先高后宽，resize 却是先宽后高，这是最常见的坑：证件照变成“横着的”就是宽高写反了。缩小用 INTER_AREA，放大用 INTER_CUBIC。
:::

## 感兴趣区域（ROI）
- 天空、树、广告牌对找车道线**没用还捣乱**
- 只处理有用的那块：**感兴趣区域**
- 本章：画面下半部分 `img[270:, :]`
- 第 3 章升级成贴合路面的“梯形”

# 2.3 颜色空间

## 为什么 RGB 不好找颜色
- 阴影里和阳光下的黄线，R、G、B 三个数**全变了**
- 人说颜色：什么颜色、鲜不鲜艳、亮不亮
- 换一种描述方法 → **颜色空间**

## HSV：色调、饱和度、亮度
![HSV 三个分量](images/hsv_channels.jpg)
- **H 色调**：什么颜色（OpenCV 中 0～180）
- **S 饱和度**：鲜不鲜艳（0～255）
- **V 亮度**：亮不亮（0～255）

::: notes
色调是一个色环：红 → 黄 → 绿 → 青 → 蓝 → 紫 → 回到红。OpenCV 把 360° 除以 2 存成 0～180。大致范围：黄 20～35，绿 35～80，蓝 100～130，红在两头（0～10 和 170～180）。
:::

## 按颜色选像素：inRange 与掩膜
```python
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
mask = cv2.inRange(hsv, (100, 100, 50), (130, 255, 255))  # 蓝色
img[mask == 255] = (255, 255, 255)                        # 换成白底
```
- 三个数都在范围内 → 255（白），否则 0（黑）
- 这张黑白图叫**掩膜**

::: notes
最后一行就是证件照换底色的核心（实验 2-1）。掩膜的思想会贯穿全书：第 6 章分割的答案就是掩膜，第 8 章修补划痕也要掩膜。
:::

# 2.4 亮度、对比度与直方图

## 调亮度和对比度
- `cv2.convertScaleAbs(img, alpha=2.0, beta=20)`
- **beta** 管亮度：每个像素都加 20
- **alpha** 管对比度：亮暗差距放大 2 倍
- 问题：一视同仁，暗处提不够，亮处先“过曝”

::: notes
实验 2-2：直接调亮后平均亮度 64.9，但有 5.8% 的像素变成了 255（过曝）。
:::

## 直方图：亮度的“体检单”
| 直方图的样子 | 说明 | 场景 |
|---|---|---|
| 挤在左边 | 偏暗 | 夜间、隧道 |
| 挤在右边 | 偏亮 | 逆光、过曝 |
| 挤在中间一小段 | 发灰 | 雾天 |
| 铺满 0～255 | 亮暗分明 | 晴天 |

::: notes
实验 2-2 的夜间画面平均亮度只有 24.0，85.1% 的像素亮度低于 50。
:::

## 直方图均衡化：把亮度“拉开”
![夜间画面的处理结果](images/night_fix.jpg)
- 按名次重新给分：挤在一起的拉开
- 彩色图只均衡 HSV 的 **V 通道**
- 平均亮度 24.0 → **93.3**

::: notes
比喻：全班成绩挤在 50～60 分，老师按名次重新给分铺满 0～100。均衡化后左边的车、右边的老人和栏杆都看清了，但噪点也被放大了，所以下一步要去噪。
:::

# 2.5 滤波去噪

## 噪声与滤波
- **噪声**：随机的亮点、暗点、颗粒
  - 椒盐噪声：纯黑纯白小点
  - 高斯噪声：一层细颗粒
- 滤波：**用邻居的值替换自己**
  - 均值：取平均
  - 高斯：近的邻居权重大
  - 中值：排序取中间，去椒盐最好

## 三种滤波对比
![三种滤波对比](images/filters.jpg)

::: notes
椒盐噪声下中值滤波几乎完全去掉了噪点；均值、高斯只是把黑白点“抹开”。高斯噪声下高斯滤波更自然。
:::

## 窗口大小：去噪和保细节
!sim filter-compare
- 3×3：轻微去噪，细节保留好
- 5×5：最常用的折中
- 7×7 以上：很模糊
- 窗口必须是**正奇数**

::: notes
实验 2-2 用 3×3 中值滤波，路面“毛糙程度”（标准差）从 27.0 降到 16.2，车辆轮廓基本保住。
:::

# 2.6 阈值与二值化

## 把图片变成黑白两色
![不同门槛的二值化](images/threshold.jpg)
- `cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)`
- 门槛不对，结果就不对
- 大津法 `THRESH_OTSU`：自动算门槛

::: notes
大津法适合前景背景亮度差别明显的图，比如白药片放在深色桌面上。二值化之后就能数块、量大小，这是第 3 章“数药片”的第一步。
:::

## Python 小课堂②：函数和循环
```python
def make_small(img, width=320):          # 定义函数
    h, w = img.shape[:2]
    return cv2.resize(img, (width, h * width // w))
for f in Path("../data/images").glob("*.jpg"):   # 逐个处理
    cv2.imwrite(f"small_{f.name}", make_small(cv2.imread(str(f))))
```
- `def` 行末有冒号，里面缩进 4 个空格

::: notes
实验 2-4 批量处理一个文件夹。`//` 是整除，保证 resize 的宽高是整数。
:::

## 常见报错
| 报错 | 意思 |
|---|---|
| `!_src.empty() in function 'cvtColor'` | 前面 `imread` 没读到图 |
| `ksize.width % 2 == 1` | 滤波窗口不是奇数 |
| `'float' … cannot be interpreted as an integer` | resize 宽高写成了小数 |
| `in function 'equalizeHist'` | 均衡化只能处理单通道 |
| 证件照“横着的” | resize 宽高写反 |
