# 1.1 什么是计算机视觉

## 看见 ≠ 看懂
| 人看图 | 计算机视觉程序看图 |
|---|---|
| 眼睛接收光线 | 摄像头把光线变成数字 |
| 大脑认出“这是一辆车” | 模型算出“车，把握 92%” |
| 根据经验判断要减速 | 按规则判断“框很大，提醒司机” |
| 从小看过无数东西 | 用大量标好答案的图片训练过 |

::: notes
计算机视觉（CV）让计算机从图片和视频中“看懂”内容：有什么、在哪里、在做什么、有多远。手机摄像头早就能“看见”，但对计算机来说照片只是几百万个数字。最后一行最关键：今天的视觉程序大多数是用大量图片“教”出来的。
:::

## 身边的计算机视觉
| 场景 | 它在“看”什么 | 任务 |
|---|---|---|
| 刷脸进站 | 是不是本人 | 检测 + 比对 |
| 停车场抬杆 | 车牌写的什么 | 检测 + 文字识别 |
| 倒车影像、车道偏离提醒 | 车道线、障碍物 | 检测、分割 |
| 抠图换背景 | 人的轮廓 | 分割 |
| 健身 App 数深蹲 | 关节怎么动 | 姿态估计 |
| 一句话生成一张画 | 按文字画图 | 图像生成 |

::: notes
这些应用看起来五花八门，拆开都是少数几种“基本任务”的组合。请学生再补充两三个例子，并说出它属于哪类任务。
:::

# 1.3 图片在计算机里的样子

## 像素：一张图就是一张数字表
!sim pixel-zoom
- 放大照片 → 一个个小方格 = **像素**
- 像十字绣：每一针一个颜色
- **分辨率**：横、纵各多少像素
- `drive_city.jpg`：1242×375

::: notes
用“像素放大镜”动画现场演示：点一个像素，看它的红绿蓝三个数；拖动分辨率体会图片的形状。手机照片常见 4000×3000（约 1200 万像素），行车视频画面 1280×720。
:::

## 颜色：红、绿、蓝三个数
| 颜色 | 红 | 绿 | 蓝 |
|---|---|---|---|
| 黑 | 0 | 0 | 0 |
| 白 | 255 | 255 | 255 |
| 纯红 | 255 | 0 | 0 |
| 黄（红 + 绿） | 255 | 255 | 0 |
| 灰 | 128 | 128 | 128 |

::: notes
每个数 0～255，因为用 8 个二进制位（1 字节）存，2⁸ = 256，类型叫 uint8。三张“颜色表”叫三个通道，所以彩色图片是“高 × 宽 × 3”的数字块。提醒：OpenCV 的通道顺序是 **BGR**（蓝、绿、红），和常说的 RGB 相反。
:::

## 灰度图：只有一个通道
- 每个像素一个数：0 黑 → 255 白
- 转灰度按人眼加权：**绿最多、蓝最少**
- 灰度 ≈ 0.299 红 + 0.587 绿 + 0.114 蓝
- 找边缘、找车道线只看亮暗，用灰度更快

::: notes
灰度图的数字只有彩色图的三分之一。很多任务只关心亮暗变化，不关心颜色。
:::

## 坐标：从左上角算起
| 写法 | 意思 |
|---|---|
| `img[100, 600]` | 第 100 行、第 600 列的像素 |
| `img[100, 600, 2]` | 这个像素的第 2 个通道（红） |
| `img[0:3, 0:3]` | 左上角 3×3 的一小块 |
| `img.shape` | `(375, 1242, 3)`：高、宽、通道 |

::: notes
原点在左上角，往右 x 增大，往下 y 增大。取像素先写行（y）再写列（x）——这是全书最容易搞反的地方，务必强调。
:::

## 视觉技术三个阶段
!mermaid 2
- **手工特征**：人告诉机器看什么（第 2、3 章）
- **深度学习**：2012 年 AlexNet，机器自己学（第 4～7 章）
- **大模型**：一个模型做很多事（SAM、Stable Diffusion）

::: notes
AlexNet 在 ImageNet 比赛中把错误率从约 26% 降到约 15%。三个阶段今天都在用：简单场景手工方法又快又好，复杂场景用深度学习，通用场景用大模型。
:::

# 1.5 贯穿项目：智能辅助驾驶助手

## “辅助”和“自动”不一样
| 等级 | 名称 | 谁在开车 |
|---|---|---|
| 0 级 | 应急辅助 | 驾驶员（系统只报警） |
| 1 级 | 部分驾驶辅助 | 驾驶员（帮控方向**或**速度） |
| 2 级 | 组合驾驶辅助 | 驾驶员（帮控方向**和**速度） |
| 3 级 | 有条件自动驾驶 | 系统，人随时准备接管 |
| 4、5 级 | 高度 / 完全自动驾驶 | 系统 |

::: notes
依据国家标准 GB/T 40429—2021《汽车驾驶自动化分级》。0～2 级是“驾驶辅助”，人始终负责开车，ADAS 就在这个范围。本书的助手只做 0 级的“看懂和提醒”，书中程序不能用于真实驾驶。这一点全书反复强调。
:::

- 第 3 章：边缘 + 直线检测找车道线
- 第 4、5 章：认车型、检测车辆行人
- 第 6 章：分出路面、估计远近
- 第 7 章：跟踪、前车过近、分心提醒

# 1.6 实验环境与工具

## 两种做实验的方式
| 方式 | 优点 | 缺点 |
|---|---|---|
| **云端 Notebook**（推荐） | 不用安装，有的送免费 GPU | 要联网，有时排队 |
| 本机 | 不依赖网络 | 第一次安装约半小时 |

- Notebook：代码分单元格，**Shift + Enter** 运行
- 必做实验 **CPU 就够**，只有第 8 章生成要 GPU

::: notes
推荐魔搭社区、飞桨 AI Studio 的 Notebook。编者在 4 核 CPU 上实测：最小的模型看一张行车照片不到 1 秒。
:::

## 两样主力工具
- **OpenCV**（`cv2`）：处理图片和视频
- **Ultralytics YOLO**：分类、检测、分割、姿态、跟踪
```python
from ultralytics import YOLO
model = YOLO("yolo26n.pt")    # 换成 -cls / -seg / -pose
results = model("照片.jpg")   # 看一张照片
```
- `26` 是版本，`n` 是最小号；**预训练模型**自动下载

::: notes
YOLO 各种任务写法几乎一样，学一次用九章。模型每个只有 5～7 MB。其他工具：NumPy、Matplotlib、MobileSAM（第 6 章）、Real-ESRGAN 和 diffusers（第 8 章）、Gradio（第 9 章）。
:::

## Python 小课堂①
| 写法 | 意思 |
|---|---|
| `print(…)` | 显示出来 |
| `y = 100` | 给值起名字（变量） |
| `# 文字` | 注释，电脑跳过 |
| `import cv2` | 请出工具箱 |
| `cv2.imread("a.jpg")` | 用工具箱的功能 |
| `f"宽 {w} 像素"` | 把变量填进一句话 |

::: notes
三个最常犯的错误：用了中文标点、大小写写错、路径写错。报错只看最后一行。
:::

## 常见报错
| 报错（最后一行） | 意思 |
|---|---|
| `No module named 'cv2'` | 没装 OpenCV |
| `'NoneType' … no attribute 'shape'` | 图片没读进来，路径错了 |
| `invalid character '（'` | 用了中文括号 |
| `index 400 is out of bounds … size 375` | 行号超过了图片高度 |
| `Download failure` | 下载模型时没联网 |

::: notes
cv2.imread 找不到文件时不报错，只返回“空”（None），到下一行用 .shape 时才报错，这是初学者最常遇到的困惑。
:::
