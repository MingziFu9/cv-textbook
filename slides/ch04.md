# 4.1 图像分类任务

## 输入一张图，输出一个类别
| 排名 | 类别 | 置信度 |
|---|---|---|
| 1 | moving_van（搬家货车） | 93.0% |
| 2 | recreational_vehicle（房车） | 6.2% |
| 3 | ambulance（救护车） | 0.2% |

- 每个类别打一个分，加起来 100%
- 分数叫**置信度**，排第一的就是答案

## Top-1 与 Top-5
- **准确率**：认对的占全部的比例
- **Top-1**：排第一的正好对
- **Top-5**：正确答案在前 5 名里就算对
- 1000 类里很多很相似（几十种狗）→ 看 Top-5

::: notes
预训练模型 yolo26n-cls.pt 在 ImageNet 的 1000 类上训练：没有“人”这一类；车分得很细却没有“轿车”大类；只看一张图里最主要的一样东西。所以要自己训练。
:::

# 4.2 卷积神经网络的直观理解

## 三种零件
| 零件 | 做什么 | 比喻 |
|---|---|---|
| **卷积层** | 一组卷积核找特征 | 一群侦探各找一种线索 |
| **池化层** | 缩小特征图 | 只记“有没有”，不记确切位置 |
| **分类层** | 汇总特征，给各类打分 | 侦探开会投票 |

::: notes
现代网络常用“步长为 2 的卷积”代替池化来缩小特征图，作用一样。
:::

## 越往后，看得越大、越抽象
!sim cnn-layers
- 宽高减半、通道增多
- 前面：边缘、颜色（像 Sobel）
- 中间：角点、车轮、车窗
- 后面：“有没有车的样子”

::: notes
在动画里选一张图和一层，看最活跃的特征图，注意特征图越来越小、通道越来越多。卷积核里每一个数都是**参数**，yolo26n-cls 约有几百万个参数。
:::

# 4.4 预训练模型与迁移学习

## 会骑自行车的人学电动车
- 平衡、看路、拐弯：**现成的本事**
- 预训练模型已经会找边缘、纹理、部件
- 只需要学“这 5 类怎么区分”
- = **迁移学习**
- 代码区别只有一个文件名

## 迁移学习到底有多大用
![从零训练和预训练模型的对比](images/transfer.png)
| 起点 | 尺寸 | 准确率 | 用时 |
|---|---|---|---|
| 从零开始 | 128 | 44.2% | 约 59 秒 |
| 预训练 | 128 | **81.4%** | 约 66 秒 |
| 预训练 | 224 | 83.9% | 约 146 秒 |

::: notes
同样 799 张训练图、10 轮，编者在 4 核 CPU 上实测。从零开始比瞎猜（20%）好不了多少。
:::

# 4.5 准备分类数据集

## 一类一个文件夹
- `road_objects/train/car/…`、`val/car/…`
- **训练集**：课本和练习题
- **验证集**：随堂测验，挑最好的一版
- 测试集：期末考试
- 训练集和验证集**不能有重复**

## 从行车照片裁出小图
![五类道路目标小图样例](images/dataset.jpg)
- KITTI 标注：类别 中心x 中心y 宽 高（0～1）
- 按框裁出：轿车、厢式车、卡车、行人、骑车人
- 每类训练 160 张、验证 40 张

::: notes
好数据集的要求：每类数量差不多、贴近实际场景、标注要准、注意许可（KITTI 是 CC BY-NC-SA 3.0，仅限非商业）。
:::

# 4.6 训练

## 一行代码开始训练
```python
model = YOLO("yolo26n-cls.pt")              # 从预训练模型出发
model.train(data="../data/road_objects", epochs=10, imgsz=128, batch=32)
```
| 参数 | 意思 |
|---|---|
| `epochs` | **轮次**：整个训练集学几遍 |
| `imgsz` | 图片缩放到多大 |
| `batch` | **批大小**：每次看几张再调参数 |

::: notes
本书小图平均一百多像素宽，imgsz=128 够用。编者 4 核 CPU 上训练 10 轮约 1 分钟。结果在 runs/road5/weights/best.pt。
:::

## 读懂训练输出
- 训练行：第 10 轮，**损失** 0.3452
- 验证行：Top-1 0.794，Top-5 1
- 损失 = 错得有多离谱，越小越好
- `best.pt`：验证集上最好的一版

## 训练曲线：欠拟合与过拟合
![训练曲线](images/train_curve.png)
- **欠拟合**：训练损失高、准确率低 → 书没读懂
- **过拟合**：训练损失降、验证变差 → 死记硬背
- 本例第 8 轮后稳定在 80% 左右

::: notes
过拟合的对策：增加数据、数据增强、少训几轮、用 best.pt。数据增强就是把训练图片随机翻转、调亮、裁剪，变出“新”图。
:::

# 4.7 评估：准确率与混淆矩阵

## 读混淆矩阵
| 真实＼预测 | 轿车 | 骑车人 | 行人 | 卡车 | 厢式车 |
|---|---|---|---|---|---|
| **轿车** | **30** | 2 | 3 | 0 | 5 |
| **骑车人** | 0 | **37** | 3 | 0 | 0 |
| **行人** | 0 | 6 | **30** | 3 | 1 |
| **卡车** | 0 | 1 | 0 | **39** | 0 |
| **厢式车** | 5 | 0 | 0 | 8 | **26** |

::: notes
行是真实类别，列是预测，对角线是认对的。总共认对 162 张、认错 37 张，准确率 81.4%。厢式车最差（66.7%），8 张被认成卡车、5 张被认成轿车。
:::

## 模型为什么会认错
![被认错的小图](images/wrong.jpg)
- 类别本身相似：小厢式车 ≈ 轿车
- 被遮挡、被截断
- 太小、太暗、太模糊
- 标注框里混着别的东西

::: notes
分析错误比提高准确率更重要。改进办法：多收集易混类别、增加遮挡样本、调大图片尺寸、清洗标注。
:::

## 常见报错
| 报错 | 意思 |
|---|---|
| `FileNotFoundError: … best.pt` | 还没训练，或路径不对 |
| `Dataset … not found` | 数据集路径不对 |
| `KeyError: 'bus'` | 字典里没有这个键 |
| `out of memory` | batch 或 imgsz 太大 |
| Top-5 总是 1 | 不是错，一共只有 5 类 |
