## 情景导入：夜里车道线不是“白色”的
- 按颜色找车道线，一到夜里就失灵
- 人开夜车靠什么认车道线？
  - 比旁边路面**亮一点** → 有一条“边”
  - 是**直的**，从车头伸到远处
- 能区分物体的线索 = **特征**

# 3.1 什么是特征

## 机器靠什么区分物体
| 特征 | 看什么 | 例子 |
|---|---|---|
| 颜色 | 像素的颜色 | 黄色车道线、红色刹车灯 |
| 边缘 | 亮暗突变 | 车道线和路面的分界 |
| 形状 | 边缘围成的样子 | 直线、圆形药片、扁长车牌 |
| 角点 | 两条边相交 | 窗户角、车牌四角 |
| 纹理 | 花纹规律 | 草地、砖墙、柏油路 |

::: notes
2012 年以前，视觉研究者的主要工作就是设计特征（手工特征）：看得懂、算得快、不需要训练数据，但规则永远补不完。3.6 节讲深度学习怎样让模型自己学特征。
:::

# 3.2 边缘检测

## 边缘：亮度突变的地方
- 车道线两侧、车身轮廓、路沿
- 找边缘 = 找**相邻像素差得多**的地方
- Sobel 核：右边一列减左边一列

| | | |
|---|---|---|
| −1 | 0 | 1 |
| −2 | 0 | 2 |
| −1 | 0 | 1 |

## Canny 边缘检测四步
- ① 高斯滤波**去噪**
- ② Sobel 算变化**强度和方向**
- ③ **细化**：粗线变细线
- ④ **双门槛**连接
  - 高于高门槛：肯定是边缘
  - 低于低门槛：丢掉
  - 中间的：和强边缘连着才留下

## 双门槛怎么定
!sim canny-threshold
| (低, 高) | 边缘像素 | 效果 |
|---|---|---|
| (10, 30) | 26378 | 太多，纹理也成了边缘 |
| (50, 150) | 8044 | 车道线清楚 |
| (150, 300) | 1897 | 太少，虚线断了 |

::: notes
常用低:高 = 1:2 或 1:3。现场在动画里拖动两个门槛，让学生说出强边缘、连上的弱边缘、被丢掉的弱边缘分别是什么颜色。
:::

# 3.3 直线与轮廓

## 霍夫变换：边缘点为直线“投票”
- 每条可能的直线 = 一个“候选人”
- 每个边缘点：凡是穿过我的直线，都投一票
- 票数最多的直线 = 真实的直线
- `threshold` 至少多少票；`minLineLength` 至少多长；`maxLineGap` 断开多远仍算一条

::: notes
一条车道线上有几百个边缘点，都投给同一条直线，票数遥遥领先；零散的噪点投出去的票分散在各处。
:::

# 3.4 卷积：一个小窗口的乘加

## 卷积怎么算
- 卷积核：一个 3×3 的小表格
- 罩在图上：**对应位置相乘，再加起来**
- 写到中心位置，然后挪一格，再算
- 像一个**放大镜**在图上一格格挪

::: notes
均值滤波、高斯滤波、Sobel 背后都是卷积。实验 3-2 手算一格得 −309，和 cv2.filter2D 算出的完全一样。
:::

## 动画：卷积核滑动
!sim conv-kernel
- 看卷积核一格格滑动、乘加出输出
- 改九个数，得到模糊、锐化、边缘

## 换一组数，换一种效果
![不同卷积核的效果](images/kernels.jpg)
| 卷积核 | 效果 |
|---|---|
| 全是 1/9 | 模糊（均值滤波） |
| 中间 5，上下左右 −1 | 锐化 |
| Sobel | 找竖直 / 水平边缘 |

## 卷积为什么适合图片
- **只看局部**：一个像素和邻居关系最大
- **到处用同一个核**：车在左边、右边都能找到
- → 参数少、找得准
- 这两点就是卷积神经网络的基础

## 模板匹配与 Haar 人脸检测
- **模板匹配**：拿着样板图找一模一样的
- **Haar 级联**（2001 年）：眼睛比脸颊暗……
  - 第一次让普通电脑实时检测人脸
  - 只认正脸，侧脸、口罩、暗光易错
- OpenCV 5 已去掉 Haar，改用深度学习

# 3.6 从手工特征到卷积神经网络

## 手工特征的天花板
| 任务 | 人设计的规则 | 什么时候失灵 |
|---|---|---|
| 找车道线 | 边缘 + 梯形 + 斜率 | 弯道、被车挡住 |
| 数药片 | 二值化 + 面积 | 颜色和桌面相近 |
| 找车牌 | 亮 + 扁长方形 | 斑马线、白招牌 |
| 找人脸 | 眼睛比脸颊暗 | 侧脸、口罩 |

## 让机器自己学卷积核

- 这就是**卷积神经网络**（CNN）

## Python 小课堂③：列表和 if
```python
lines = [8, 7]                 # 列表：左右各几条
print(lines[0])                # 下标从 0 开始 → 8
if lines[0] > 5:               # 条件后面要冒号
    print("左边线段够多")
```
- `==` 是等于（两个等号），`=` 是赋值

## 常见报错
| 报错 | 意思 |
|---|---|
| `'NoneType' object is not subscriptable` | 霍夫一条线也没找到 |
| `findContours` 格式错误 | 要用单通道黑白图 |
| `list index out of range` | 下标超出了列表长度 |
| `if` 那一行 `invalid syntax` | 少了冒号或 `==` 写成 `=` |
| `no attribute 'CascadeClassifier'` | OpenCV 5 已去掉 Haar |
