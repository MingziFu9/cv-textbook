# 6.1 为什么要分割

## 框不够用的时候
| 场景 | 框的问题 | 分割能做什么 |
|---|---|---|
| 人像模式、换底色 | 框里还有背景 | 精确抠出轮廓 |
| 判断“哪里能开” | 路面框不住 | 标出每个路面像素 |
| 量病斑、裂缝面积 | 框远大于实物 | 数掩膜像素 |
| 挨在一起的车 | 框互相重叠 | 每辆车一个轮廓 |

::: notes
实验 6-3 中，同一辆车的检测框面积 49 671 像素，真正的车身只有 34 817 像素，只占框的 70%。
:::

## 三种分割
![同一张街道照片的三种分割](images/seg_types.jpg)
- **语义**：每个像素是什么类别
- **实例**：每个物体是第几个
- **全景**：两件事都做

## 三种分割怎么区分
| | 语义 | 实例 | 全景 |
|---|---|---|---|
| 挨着的两辆车 | 分不开 | 车 1、车 2 | 车 1、车 2 |
| 路面、天空 | 有类别 | 不管 | 有类别 |
| 比喻 | 给地图涂色 | 给同学剪剪影 | 两件事都做 |
| 本书模型 | yolo26n-sem | yolo26n-seg | 两者合并 |

::: notes
全景分割的说法来自 2019 年 Kirillov 等人：数得清的东西（人、车）叫 things，数不清的东西（路面、天空）叫 stuff。
:::

- 鼠标移到画面上，看每个像素被分成什么

# 6.2 掩膜：分割的答案

## 掩膜是一张黑白图
![实例分割结果、一个人的掩膜和换背景](images/mask_cutout.jpg)
- 实例分割：每个物体一张 0/1 掩膜
- 语义分割：一张类别编号图（0 路面、13 轿车）
- 第 2 章 `inRange` 也得到过掩膜

::: notes
算一算：实验 6-1 中第一个人的掩膜有 49 302 个 1，整张图 810 × 1080 = 874 800 像素，占 5.6%；公交车占 29.2%。
:::

## 用掩膜换背景
- 新图 = 原图 × 掩膜 + 新背景 × (1 − 掩膜)
- 掩膜是 1：取原图；是 0：取新背景
- 衣服上有蓝色也不会被误换
- 边缘有锯齿 → 高斯滤波**羽化**

```python
mask3 = mask[:, :, None]                 # h×w → h×w×1
out = img * mask3 + blue * (1 - mask3)
```

::: notes
算一算：边缘像素原图 (200, 180, 160)，新背景 (219, 142, 67)，羽化后掩膜 0.5，新图约 (209, 161, 113)，正好一半一半。
:::

## 分割数据怎样标注
- 检测“画框”，分割要**描边**
- **多边形标注**：沿轮廓点一圈点
- 每行：类别 + 一对对 x、y 比例坐标
- 描一个人要几十个点 → 数据很贵
- SAM 辅助：点一下自动出轮廓

# 6.3 分割模型

## U-Net：先缩小、再放大
!mermaid 1
- **编码器**：压缩，“这里有什么”
- **解码器**：放大，“每个像素是什么”
- 跳跃连接把细节直接传过去

::: notes
U-Net 2015 年提出，最早用在医学影像，至今仍是医学图像分割最常用的结构之一。Mask R-CNN（2017，何恺明等）是另一条路：Faster R-CNN 先找框，再在框里画掩膜。
:::

## YOLO 的分割模型
| 模型文件 | 任务 | 输出 |
|---|---|---|
| `yolo26n.pt` | 检测（COCO 80 类） | `r.boxes` |
| `yolo26n-seg.pt` | 实例分割（COCO 80 类） | `r.masks` |
| `yolo26n-sem.pt` | 语义分割（城市道路 19 类） | `r.semantic_mask` |

- `retina_masks=True`：掩膜和原图一样大

## 分出可行驶路面
![城市街道照片的语义分割](images/sem_city.jpg)
- 紫色路面、粉色人行道、深蓝轿车
- 路面占整张图 **16%**
- 19 类来自 Cityscapes（欧洲城市）

::: notes
实验 6-2 只看车头前方区域：城市街道 81% 是路面、3% 是车和人；路口 83% 路面、16% 车和人，提示“减速”；高速 99% 路面、0% 车和人。
:::

## 分割的评估
- **掩膜交并比**：数交集、并集的像素
- 例：A 6 个、B 7 个、交集 5 → 5 ÷ 8 = 0.625
- 实例分割：**掩膜 mAP**
- 语义分割：**平均交并比**（mIoU）
- 会读即可，本书不训练分割模型

# 6.4 分割一切模型 SAM

## 点一下就能分割
![SAM 点选和检测框 + SAM](images/sam.jpg)
- 给一个**提示**：点或框
- 不管叫什么，把“这一整块”分出来
- MobileSAM 约 40 MB，CPU 约 3 秒一次

::: notes
SAM 由 Meta 在 2023 年发布，用 1100 万张图片、10 亿多个掩膜训练。实验 6-3：在黑色轿车上点一下，得到 34 524 像素的掩膜，模型打分 0.88。
:::

## 动画：点一下分割
!sim sam-click
- 点车、路面、天空、护栏
- 被点中的完整一块亮起来
- 打开“显示全部区域”看一共几块

## 一个点有好几种理解
- 点白色小车车尾：只分出上半部分（0.59）
- 改用框：整辆车（0.94）
- 对策 ①**改用框** ②多点几个点
- 对策 ③**先检测再分割**：YOLO 框 → SAM

::: notes
点选 1331 像素，框选 3461 像素。“先检测再分割”既知道“是什么”（来自 YOLO），又有精确轮廓（来自 SAM），实验 6-3 中车身只占框的 70%～78%。
:::

## SAM 和 YOLO 分割怎么选
| | YOLO 分割 | SAM |
|---|---|---|
| 要提示吗 | 不要 | 要，点或框 |
| 说出类别 | 能 | 不能 |
| 没训练过的东西 | 分不出 | 也能分 |
| 速度（CPU） | 不到 1 秒 | 约 3 秒一次 |
| 适合 | 辅助驾驶、计数 | 交互抠图、辅助标注 |

# 6.5 深度估计：场景重建的第一步

## 每个像素一个“远近”
![城市街道照片的深度图](images/depth.jpg)
- **深度图**：每个像素离相机多远
- 近处红、远处蓝
- 本例 5.4～86.6 米

::: notes
实验 6-4 用 yolo26n-depth.pt：最近的轿车约 6.5 米，行人约 11.2 米，10 米以内画红框。数值可以大致理解为“米”。
:::

## 一张照片怎么看出远近
| 线索 | 例子 |
|---|---|
| 近大远小 | 近车框 290×172，远车 33×24 |
| 越靠下越近 | 中间一列：7.4 / 59.7 / 77.1 米 |
| 遮挡 | 挡住别人的更近 |
| 纹理变密 | 车道线越远越密 |

- 只用一个摄像头：**单目深度估计**

## 辅助，不是替代
- 单目深度：便宜，但**没有绝对尺子**
- 换镜头、换场景，数值可能偏差很大
- 真正测距：双目、毫米波雷达、激光雷达
- “约 6.5 米”是**估计**，只做提醒

::: notes
请学生讨论：智能辅助驾驶助手可以用它说“前车较近，注意保持距离”，但不能据此控制车辆。驾驶员始终要自己观察路况。
:::

## 从深度到三维：场景重建
| 技术 | 做法 | 生活中的例子 |
|---|---|---|
| 单目深度估计 | 一张照片 → 深度图 | 人像虚化、AR 放家具 |
| 多视角重建 | 拍一圈 → 三维模型 | 文物数字化 |
| NeRF、高斯泼溅 | 一段视频 → 自由视角 | 实景三维、虚拟看房 |
| 鸟瞰图、占用网络 | 多摄像头 → 俯视地图 | 车辆周围示意图 |

## Python 小课堂：用掩膜挑像素
```python
road = (sem == 0)                    # 比较 → True/False 表
print(road.mean())                   # 路面占比 0.16
show[road] = (0, 200, 0)             # 布尔索引：只改 True 的像素
car = np.isin(sem, [13, 14, 15])     # 一次比较多个值
mask3 = mask[:, :, None]             # (h, w) → (h, w, 1)
```

## 常见报错
| 报错 | 意思 |
|---|---|
| `'NoneType' … no attribute 'data'` | 用了检测模型，没有 masks |
| `can't convert … tensor to numpy` | 加 `.cpu().numpy()` |
| `could not be broadcast … (1080,810)` | 掩膜少一维，用 `[:, :, None]` |
| `index 0 is out of bounds` | 一个人也没找到 |
| 人物边缘一圈锯齿 | 加 `retina_masks=True`，再羽化 |
