# 8.2 扩散模型

## 加噪：训练时做什么
![一张行车照片逐步加噪](images/noise_steps.jpg)
- 每次撒一点“雪花”，1000 步变成纯噪声
- 训练：给加了噪的图，**猜出噪声**
- 猜得越准，模型越会“去噪”

::: notes
算一算：第 t 步的图 = √ᾱ × 原图 + √(1 − ᾱ) × 噪声。按常用设置，第 100 步 ᾱ ≈ 0.90（原图还占 90%），第 300 步约 0.40，到第 1000 步几乎为 0。
:::

## 去噪：生成时做什么
- ① 从纯噪声出发（**随机种子**决定）
- ② 猜出噪声，减掉一点
- ③ 重复几十步，图慢慢“洗”出来
- 先出大块明暗，再出轮廓，最后修细节
- 步数太少 → 细节不够

## 文字怎样引导画面
- 每一步猜噪声时，把**文字**也告诉模型
- 文字编码器：和 CLIP 同一类
- “朝着‘雨天的路口’去噪”
- **潜空间**：先压缩再扩散，计算量小得多

# 8.3 Stable Diffusion 怎么用

## 五个参数
| 参数 | 含义 | 常用值 |
|---|---|---|
| 提示词 | 想要什么 | 越具体越好 |
| 反向提示词 | 不想要什么 | 模糊、变形、水印 |
| 步数 | 洗几次 | 20～30 |
| 引导强度 | 多听提示词 | 7～8 |
| 随机种子 | 起点噪声 | 相同种子可复现 |

::: notes
引导强度太低画面跑题，太高颜色过饱和、生硬。步数超过 30 以后变化不大，只是更慢。
:::

## 写提示词：主体 + 场景 + 细节 + 风格
- 主体：a city street intersection
- 视角：seen from a car dashboard camera
- 细节：heavy rain, wet road, reflections
- 风格：realistic photo
- 反向：cartoon, blurry, text, watermark

::: notes
开源模型大多英文效果更好；通义万相、即梦、可图等国产平台对中文支持很好。做对比实验要固定随机种子，每次只改一个参数，像物理实验的“控制变量”。
:::

## 图生图、局部重绘、ControlNet
| 方式 | 做法 | 关键 |
|---|---|---|
| 图生图 | 照片加部分噪声再去噪 | strength 0.3～0.7 |
| 局部重绘 | 只在遮罩里重画 | 遮罩可来自分割 |
| ControlNet | 按边缘、深度图控制结构 | 原标注可复用 |

## 用生成数据训练辅助驾驶模型
| 好处 | 风险 |
|---|---|
| 补暴雨、大雪、浓雾、逆光 | 模型学到“生成图的特征” |
| 补行人冲出等危险场景 | 细节不合理：车道线断开 |
| 不用冒险拍，成本低 | 标注要重新检查 |

- **真实数据为主、生成数据为辅**，用真实数据测试

# 8.4 图像修复

## 传统修补：用周围像素“填”
![老照片修补前后对比](images/restore.jpg)
- TELEA：从边缘一圈圈往里填
- NS：沿等亮度线把颜色“流”进来
- 适合细小划痕；大块缺损要靠扩散模型

::: notes
实验 8-2：划痕处平均亮度 234.9，修补后约 99，和周围融为一体，TELEA 和 NS 在这张照片上几乎一样。老照片由编者用 KITTI 照片模拟做旧。
:::

## 遮罩从哪里来
| 方法 | 找到的像素 | 交并比 |
|---|---|---|
| 亮度 > 225 | 27 726 | 0.10 |
| 顶帽运算 | 3452 | 0.50 |

- 难点不是“补”，是**找出要补的地方**
- 亮度法：天空、斑马线也被当成划痕
- 顶帽：只留“比周围亮的细小东西”

# 8.5 超分辨率

## 插值放大为什么会糊
- 放大 4 倍：凭空多出 15 倍像素
- 最近邻：复制 → 马赛克
- 双三次：16 个邻居平均 → 发糊
- **超分辨率**：模型按经验“猜”出细节

::: notes
本书用 Real-ESRGAN（腾讯 ARC 实验室等，2021），用模拟的真实退化训练，对老照片、网络图片效果好。模型约 5 MB，CPU 0.08 秒一张。
:::

## 清楚不等于真实
| 方法 | 平均误差 | 清晰度 |
|---|---|---|
| 最近邻 | 10.3 | 791.8 |
| 双三次 | 9.2 | 32.2 |
| 超分辨率 | **11.8** | **666.5** |
| 原图 | 0 | 1008.4 |

- 最清楚，误差却最大：细节是**猜**的

## 超分辨率不能当证据
- 数字指标要和眼睛看结合
- 模糊车牌、人脸“超分”出来是**猜的样子**
- 不能用来认定是谁、是哪辆车
- 好看 ≠ 真实

## 常见报错
| 报错 | 意思 |
|---|---|
| `OutOfMemoryError` | 显存不够，用 float16、改小尺寸 |
| `Torch not compiled with CUDA` | 没有 GPU，去云端运行 |
| 下载模型很慢 | 用 hf-mirror 或魔搭社区 |
| 生成全黑图 | 安全过滤器触发，改提示词 |
| `inpaint … mask` | 遮罩要单通道 uint8 |
